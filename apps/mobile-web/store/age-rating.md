# Age rating (draft answers)

Target: **4+** (App Store) and **Everyone** (Play, IARC). The app is used by adults (18+, enforced
at sign-up) to store photos of their own baby; it contains no objectionable content of its own.

## App Store Connect questionnaire

| Question | Answer |
| --- | --- |
| Cartoon or fantasy violence; realistic violence; prolonged graphic violence | None |
| Sexual content or nudity; graphic sexual content | None |
| Profanity or crude humour | None |
| Horror/fear themes | None |
| Alcohol, tobacco or drug use or references | None |
| Simulated gambling; contests | None |
| Medical or treatment information | None (notes are the parent's own; the AI never infers health conditions) |
| Unrestricted web access | No (links to our own site and the privacy page only) |
| User-generated content | Yes, but private: content is visible only to the account holder and people they invite or share with; no public feed. Parents can delete anything. |
| Messaging or chat with other users | No (the Chat tab is an AI assistant about the user's own album) |
| Location sharing with other users | No |
| Made for kids / kids category | No (audience is parents) |

## Google Play (IARC) questionnaire

Category: Utility/Productivity or Photography. Violence, sexuality, language, controlled
substances, gambling: all No. User interaction: users can share content with people they choose
(private links); no public interaction; location not shared. Expected rating: Everyone.

Because the app handles photos of children, answer the Play "Families" question as: app is **not**
designed for children; target audience is adults 18+.
